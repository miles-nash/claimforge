# Frontier Push Experiment

This workspace is for a 30-minute-cycle Codex research experiment.

Mission: move the frontier on autonomous, verifiable scientific research by making agents better at reproducing, falsifying, and stress-testing computational claims.

The narrow world-class target for the next few weeks:

> Codex-native research verification: a reproducibility-first agent workflow that can take a published ML/science claim, plan the right experiment, run it, and produce a checkable artifact.

Why this target:

- It is hard and consequential: science is only useful when claims survive contact with evidence.
- It is suited to token-rich agent work: literature review, code reading, experiment setup, benchmark running, and writeups can compound every 30 minutes.
- It is measurable: CORE-Bench, PaperBench, FIRE-Bench, MLE-Bench, replication reports, PRs, issues, and reproduced figures give external checks.
- It is narrow enough to become unusually good at quickly: not "solve science," but "make agentic research verification less brittle."

Current hypothesis:

> The fastest useful frontier movement is not more autonomous paper writing. It is a better planning and verification harness for research agents, because current agents fail often at experimental planning and reproducibility.

## Operating Loop

Each cycle should leave at least one durable trace:

1. Read or run something real.
2. Convert it into a claim, artifact, benchmark result, patch, or decision.
3. Record evidence and the next highest-leverage step.
4. Ask Miles only for access, compute, or human judgment that blocks progress.

## Early Milestones

- Day 1: pick target benchmark/task family, create a project log, identify access needs.
- Day 2: run or dry-run one benchmark/task harness locally.
- Day 3: complete one small reproducibility case study with a public artifact.
- Week 1: publish a concise technical note or repo artifact explaining one failure mode and one fix.
- Month: produce a measurable improvement, useful dataset, benchmark trace, reproducibility report, or upstream contribution.

## Access Wishlist

- GitHub access to create/push a public repo and open issues/PRs.
- Hugging Face token for datasets/models.
- OpenAI API key or Codex token path usable from local scripts.
- Optional: Kaggle credentials for MLE-Bench-style tasks.
- Optional: GPU/cloud credits for heavier replications.
- Optional: calendar/Gmail access for nudging Miles or contacting researchers when blocked.
